ROBO TIPMINER BLITZ4 DOUBLE — TESTE GRATUITO RENDER WEB

ATENÇÃO: esta configuração é SOMENTE para teste. O serviço Web gratuito do Render pode dormir após período sem tráfego e seu disco é efêmero. Portanto não garante execução 24h, consulta ininterrupta a cada 30 segundos nem preservação de memória após reinicializações.

ARQUIVOS
- engine_v15.py: motor analítico extraído do notebook fornecido.
- worker.py: ciclo de análise a cada 30 segundos enquanto o processo estiver ativo; alerta apenas para SINAL FORTE/MODERADO com API atualizada e proteção aprovada.
- web_app.py: endpoints / e /status para o Render aceitar serviço Web.
- historico_acumulado.json: histórico inicial fornecido (10.992 registros).
- Dockerfile / requirements.txt / render.yaml: implantação.

CONFIGURAÇÃO
1. No GitHub, substitua os arquivos antigos pelos arquivos desta pasta (upload dos arquivos na raiz do repositório; confirmar substituir os existentes).
2. No Render, crie New > Web Service e escolha o repositório actionmenestre/robo-blitz4.
3. Runtime Docker; branch main; Root Directory vazio; Instance Type Free.
4. Environment Variables: DATA_DIR=/tmp/blitz4-data; POLL_SECONDS=30; TELEGRAM_BOT_TOKEN e TELEGRAM_CHAT_ID (preencher diretamente no painel Render, nunca no GitHub).
5. Deploy. Verifique /status e os Logs.

LIMITAÇÕES DO PLANO GRATUITO
- O serviço pode dormir após 15 minutos sem requisições HTTP de entrada.
- Sistema de arquivos é efêmero: histórico acumulado e deduplicação de alertas podem ser perdidos ao reiniciar/reimplantar.
- Não use como robô operacional contínuo. Para operação 24h com memória persistente é necessário serviço pago com disco persistente ou outra infraestrutura apropriada.

SEGURANÇA
Nunca publique TELEGRAM_BOT_TOKEN nem TELEGRAM_CHAT_ID no repositório. Não há garantia de resultado de apostas; sinais são estatísticos e experimentais.
